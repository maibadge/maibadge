# MaiBadge

MaiBadge PCB designs, artwork, and firmware.

The maintained CircuitPython firmware for both the bear-shaped and
machine-shaped PCBs is in
[`code/circuitpython-full-slop-port`](code/circuitpython-full-slop-port).
Choose `bear_v1` or `machine_v2` in that directory's `settings.toml` before
uploading. See the
[`manual upload guide`](code/circuitpython-full-slop-port/MANUAL_UPLOAD.md) for
complete installation instructions.
